## 1. 프로젝트명

후위얼.zip

## 2. 프로젝트 소개

후위얼.zip은 팀원들의 자기소개를 파일 형태로 관리하는 웹페이지로, 각 팀원의 정보를 확인하고 새로운 팀원을 추가하거나 기존 팀원을 삭제할 수 있는 기능을 제공한다.

## 3. 프로젝트 목표

- HTML, CSS, JavaScript를 활용한 웹페이지 제작
- 팀원 정보를 효율적으로 관리하는 기능 구현
- 사용자와 상호작용하는 웹 기능 학습
- 자기소개를 재미있고 직관적으로 표현

## 4. 주요 기능

### 1) 팀원 조회

- 등록된 팀원 목록 확인
- 팀원별 자기소개 확인

### 2) 팀원 추가

- 이름, 취미, 장래희망 등 입력
- 새로운 팀원 카드 생성

### 3) 팀원 삭제

- 선택한 팀원 정보 삭제
- 목록 자동 갱신

### 4) 자기소개 카드

- 프로필 사진
- 이름
- 취미
- 관심 분야
- 장래희망
- 노래 (BGM)
- 능력치
- 가방 속 물건으로 소개

## 5. 사용 기술

- HTML
- CSS
- JavaScript
- Pigma

## 6. 기대 효과

- 웹 개발 기초 역량 향상
- 데이터 추가 및 삭제 기능 구현 경험
- 팀원 간 소통 및 협업 능력 향상
- 사용자 친화적인 웹페이지 제작 경험
